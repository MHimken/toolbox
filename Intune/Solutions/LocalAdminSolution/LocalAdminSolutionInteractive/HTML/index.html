Usage guidance

The report shows observed local-administrator access paths. It does not prove that a device is currently reachable or that a requested change was completed.

  • Direct entries are assigned on the endpoint. Transitive entries come through a directly assigned group.
  • Governance approval is organization-wide. Personal acknowledgement only changes the current user's review queue.
  • Review current mismatches daily during incidents, weekly for normal operations, and monthly for formal exception governance.
  • CSV exports contain protected operational data. They include every filtered row in the current sort order, not only the visible page.
  • Governance proposals start as pending approval. Approving, rejecting, or revoking rules requires Admin mode, which the protected backend verifies through an app role, a Conditional Access authentication context, and a token issued within the last 30 minutes. Admin mode ends after 15 minutes without activity, on sign-out, or when the account changes.
  • A host-provided config.json contains public defaults only. Values used by this browser can always be observed and must never include credentials.
  • Use exact CORS origins where possible. An allow-all origin is available for controlled testing, but permits requests from any website.

Propose governance rule

Proposals start as pending approval. A governance approver must activate them in Admin mode. Your own proposals need a second approver unless you hold the self-approval role.
